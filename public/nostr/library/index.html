Knowledge base logic

A good wiki gives every kind of reader a different first move.

Some readers need a short explanation. Some need evidence. Some compare products. Some are building. The Library works because those jobs are separated instead of mixed into one endless list.

01

Learn the idea

Open Basics, Start or a field guide when the question is still conceptual.

02

Find the source

Use the Source Inventory when the claim needs a crawl trail, repository or article.

03

Compare products

Move into Apps, Wallets, Relays or Media when the decision is practical.

04

Read the standard

Open NIPs when the behavior depends on a shared implementation rule.

05

Follow the people

Use People and Media when a topic is best understood through builders and voices.

06

Improve the map

Send source gaps, corrections and duplicate findings into the Community review layer.
